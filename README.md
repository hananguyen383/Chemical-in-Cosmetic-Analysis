# 📊 Chemical-in-Cosmetic-Analysis

This dashboard analyzes cosmetic chemical usage and product trends using Excel, SQL, and Power BI. It highlights discontinued chemicals, frequently used ingredients, products containing discontinued chemicals, and key dates to support data-driven insights and decision-making in the cosmetics industry.

🎯 **Goal:** Analyze cosmetic chemical and product data to identify usage patterns, discontinued chemicals, and potential product impacts.

📋 **Description:** This project uses government-published data [Catalog.data.gov](https://catalog.data.gov/dataset/chemicals-in-cosmetics?from_hint=eyJxIjoiaGVhbHRoIGNhcmUgY29zbWV0aWMiLCJzb3J0IjoicmVsZXZhbmNlIn0%3D) to analyze chemicals used in cosmetic products and identify trends in chemical usage, discontinued ingredients, affected products, and significant dates.

🧠 **Skills:**
Data Cleaning, Data Transformation, Data Analysis, Exploratory Data Analysis (EDA), Data Visualization, Dashboard Development, Business Insights.

🛠️ **Technology:**

Excel – Data cleaning and preparation

SQL – Data querying, filtering, and analysis

Power BI – Data visualization

📊 **Results / Key Insights:**

The Procter & Gamble Company has the highest number of discontinued chemicals among the companies shown, with approximately 2,900 discontinued chemicals, considerably higher than the other companies.

Titanium dioxide is by far the most frequently used chemical in the dataset, accounting for approximately 91% of the recorded chemical usage, making it the dominant ingredient in this analysis.

The dashboard identifies multiple products containing discontinued chemicals, with the highest-listed product containing 156 discontinued chemicals, highlighting products that may require further review or monitoring.
